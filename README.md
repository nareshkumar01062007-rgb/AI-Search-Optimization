# AI-Search-Optimization
Search algorithms are used to find the best solution from a set of possible solutions.
In this project, we study State Space, Local Search, Global Search, Local Optimum, Global Optimum, Exploration, Exploitation, Hill Climbing, and Simulated Annealing.

Examples such as Sudoku, Eight Queens, and Job Interview Scheduling are used to understand these concepts.

2. State:

A state represents one possible situation or solution of a problem.

3. State Space

State Space is the collection of all possible states or solutions of a problem.

4. Search

Search is the process of exploring the state space to find a good or best solution.

5. Local Search

Local Search focuses on the current state and its nearby neighbouring states instead of exploring the complete state space.

6. Global Search

Global Search explores different regions of the state space to find a better overall solution.

It is useful when the search can get stuck in a local optimum.

Simulated Annealing is an example of a search technique that can explore beyond local regions.
